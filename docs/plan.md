# MidiDraft 立项与 90 天执行方案（记录）

原文：[音频转 MIDI 新站：立项与 90 天执行方案](https://my.feishu.cn/docx/WELldg0Bdo2E49xelGnclIAonlg)
（飞书，2026-09-23 按 revision 7 记录；研究日期 2026-09-20）。原文是准据，本文件是仓库内的摘要，
两者不一致时以原文为准，并同步更新这里。

`src/config/product.ts` 里的范围、功能开关和价格都来自这份计划。

## 一句话

做一个面向独立音乐制作人的 Audio / MP3 / WAV to MIDI 专站。免费提供真正可下载的基础转换，
验证「转录后批量清理与导出」能否收费。先花不超过 5,000 元做 90 天实验，剩余资金按结果释放。

> 这是有搜索需求依据、但付费差异仍需验证的实验。不要当成已证明盈利的 SaaS，
> 也不要按竞品全站流量推算收入。

- 定位：**Turn audio ideas into editable MIDI drafts, then clean and export them for your DAW.**
- 「Draft」刻意表达可编辑草稿。不宣传「一键准确分离全部乐器」「零误差扒谱」。
- 适用条件：1 人开发，前三个月现金预算 5,000–15,000 元（不含工资和设备），先做海外英语市场。

## 1. 竞品取舍

选 **AI-MIDI 的聚焦程度 + Jukeblocks 的免费入口与制作人工作流**，参考 Songscription 的
「先体验后付费」和结果展示。首期不复制 Musci / CraftMusic 的综合生成平台和多语言矩阵。

| 竞品 | 借鉴 | 对本项目的决定 |
|-|-|-|
| Songscription | 转录结果可试听、编辑、导出，付费对应具体交付 | 学转化流程；第一版不做乐谱、指法谱、曲库 |
| AI-MIDI | 产品聚焦，额度与定价清楚 | 学聚焦；不买它的 API 做无限免费入口 |
| Jukeblocks | 免费转换接制作人后续工作流 | 免费 MIDI 获客；只做标准 MIDI 后处理，不碰 FLP/ALS 互转 |
| Musci | 把有搜索的工具做成入口 | 只扩展同一制作流程，不追流量最大化 |
| CraftMusic | 少量英文页覆盖多种说法 | 不先铺几十页再找收费理由 |

**目标用户**：手上有一段自己的钢琴 / 吉他 / 合成器 / 人声旋律，想在 Ableton、FL Studio、Logic
里继续做。优先桌面；手机先保证试听和短片段可用。

**首个付费场景**：制作人有 10 个 15–60 秒的单乐器 loop，逐个转 MIDI 后要删碎音、调节奏、
统一长度、命名、打包。检验他愿不愿意为少做这些重复操作付 7–12 美元。

## 2. 功能分期

### 第 1 阶段：免费基础工具（约 2–3 周）——已完成

| 功能 | 要求 | 现状 |
|-|-|-|
| 输入 | 本地 MP3/WAV，桌面限 3 分钟、30MB；可选 15–60 秒片段 | 已做 |
| 转录 | 清晰单乐器优先，Basic Pitch 作基线 | 已做（浏览器本地推理） |
| 试听 | 原音 / MIDI 一键切换、同一播放位置、可循环 | 已做 |
| 结果查看 | 轻量钢琴卷帘，显示音符、时长、速度 | 已做 |
| 基础调整 | 灵敏度、最短音符、音高范围，可撤销重置 | 已做（另加清理与量化） |
| 导出 | 免费下载标准 `.mid`，写入正确 tempo | 已做 |
| 异常处理 | 取消、进度、解码失败、内存不足时可截短重试 | 已做 |
| 示例 | 3 个原创示例，含一例局限演示 | 已做 |
| 隐私 | 音频不上传；统计不采集文件名或音频内容 | 已做（见 `docs/analytics.md`） |

原则：免费导出不要求注册；不让用户等完转换才第一次知道要付费；收费入口出现在用户准备
「批量完成同类工作」时。

### 第 2 阶段：收费实验（约第 4–6 周）——未开始

只做两个模块：

1. **Batch 工作流**：最多 10 个短片段顺序处理；统一参数、文件命名、失败重试、ZIP 打包；
   限制批量总时长（例如 20 分钟，以实测设备为准）；说明浏览器关闭后任务不保证继续。
2. **Cleanup 预设与比较**：对碎音、重复音符、重叠、量化强度、音区过滤做可撤销组合；保存预设，
   一次应用于整批；处理前后可试听。

这是效率假设，不是独占算法，必须和免费工具、DAW 自带功能比较（已有 Convert Town、PureMIDI、
MIDI Toolbox 等免费方案）。2–3 周做不完就继续缩小，不用「再做个 AI 生成器」转移问题。

对应代码：`productConfig.features.batch` / `cleanupPresets` / `paidPlans`，完成后才能打开。

### 第 3 阶段：有证据后才加

- `.mid` 文件直接导入清理（`features.midiImport`，读取函数 `midiFileToNotes` 已写好，未接界面）。
- 更长文件、本地工程保存、更多乐器预设：按实际请求排序。
- 云端增强转录或分轨：先测单位成本和质量，单独收费。
- 首期不做：PDF / MusicXML / 吉他谱、整首多轨、YouTube 链接输入、DAW 工程转换、曲库、API、多语言。

### 收费前的质量验收（自设门槛，尚未实测）

建 30 段测试集：清晰钢琴 / 吉他 / 合成器 / 人声各 5 段，另 10 段噪声或复杂混音作边界集。
简单集与困难集分开报告。

- 清晰样本至少 16/20 给出可辨识、可继续编辑的主要音符草稿。
- 有效输入的完成并导出率 ≥ 90%；导出文件在至少两个 DAW 里正确打开、按预期速度播放。
- 桌面基准设备上，60 秒清晰音频转换中位耗时 ≤ 60 秒（同时记录 P90、首次加载、缓存后）；做不到就缩短默认片段。
- 5 位目标用户对比「现有免费方案」与本工具：清理到可用的中位总耗时降不到约 30%，Cleanup 不成立为收费差异。
- 移动端单独测。

页面规则（已在代码里落实）：

- **首页就是工具页**，不建与首页竞争的 `/audio-to-midi`。
- 首批公开页约 10–12 个；功能没完成的页面不公开（`NotLaunched` + `noindex` + 不进 sitemap）。
- 首页 title：`Audio to MIDI Converter — Free MP3 & WAV to MIDI | MidiDraft`；H1：`Turn MP3 & WAV into Editable MIDI`。
- 每周 1 篇有真实输入输出的教程，90 天累计 6–8 篇。首批主题：FL Studio 导入、Ableton 导入、减少碎音、为什么和弦混音转不好、如何选片段、MIDI 与音频的区别。
- 上线即接 Search Console 和分析；前 60 天只做英文。
- 观察 4–6 周查询数据后再决定是否拆 `voice to midi` 等页面；依据是独立任务和搜索结果差异，不是关键词字面不同。

## 4. 域名

首选 **mididraft.com**，品牌 MidiDraft（短、能解释「MIDI 草稿」、可扩展到清理和批量）。
备选 miditidy.com、looptomidi.com。首年预算 ≤ 200 元，不买溢价域名，只注册一个主域名，
不把他人品牌写进域名。（已采用 mididraft.com。）

## 5. 定价

不和免费基础转换打价格战，用户为**节省重复处理的时间**付费。
**价格是待测试方案，不是根据竞品价格推导出的已验证最优价。**

| 方案 | 价格 | 权益 | 上线时间 |
|-|-|-|-|
| Free | $0 | 单文件、最长 3 分钟、A/B 对比、基础参数、标准 MIDI 下载；不强制注册 | 首版（已上线） |
| Project Pass | **$7 / 7 天，一次性，不自动续费** | 批量、清理组合预设、打包下载；受每批长度与设备能力限制 | 收费实验 |
| Pro | **$12 / 月，自动续费** | Pass 功能持续可用、预设保存 | 收费实验 |
| Pro 年付 | 可测试 $89 / 年 | 有真实使用与留存后才上线，不用年付掩盖续费问题 | 最早第 3 个月后 |

- 两个付费入口面向不同频率：偶尔整理一个项目买 Pass，持续制作的人订阅 Pro。首期不做多档位、积分、终身套餐。
- 参考的竞品月付（2026-09-20 公开页）：Songscription $9.99 / $29.99；AI-MIDI $9.99 / $19.99 / $39.99；
  Jukeblocks 约 €11.99–14.99；Musci $9.99 / $29.99 / $99.99；CraftMusic $14.99 / $29.99 / $49.99。
  能力不同，不能直接比性价比。
- 付费路径：免费完成一首 → 试听 → 发现还有一批文件 → 点「处理整批」→ 先用自己一个文件预览清理效果 → 看见完整费用与限制 → 购买。
- 付款界面写清币种、税费、是否续费、取消位置、权益期限；首次购买 7 天内可申请退款。不承诺用户上传的作品因此获得商用许可。
- **为什么不送云端分钟数**：AI-MIDI API 摊销约 $0.21–0.22/分钟；每月 1 万访问、30% 各免费转一首 3 分钟，免费计算就要约 $1,900/月。所以 Free 和付费首期都只卖本地处理。未来上云要按有效分钟成本单独定价（内部门槛 ≤ $0.05/分钟，不是已有报价）。

## 6. 外链

90 天目标：**8–15 个真实相关的引用域**，并记录带来的访问、使用和付费（控制工作量的目标，不是排名保证）。

先准备 3 样值得被引用的东西：公开小测试集（20 段许可明确的音频 + 原始 / 清理后 MIDI）、
一篇有数据的教程（手工清理 vs 批处理各花多久）、免费工具本身。

| 渠道 | 做法 |
|-|-|
| 音乐制作媒体（如 Bedroom Producers Blog） | 精选约 10 个，按正式投稿方式介绍，不承诺链接 |
| Ableton / FL Studio 小型教程作者 | 筛约 10 人，最多测 2–3 次合作，有偿合作要披露 |
| Product Hunt | 一次集中发布，不买票 |
| AlternativeTo + 3–5 个相关工具目录 | 如实描述，先免费 |
| 音乐教师 / 制作人博客 | 帮他们修订过时教程，由站长决定是否引用 |
| 社区与论坛 | 每周 2 次有内容的参与，先读板规、表明作者身份 |

每周节奏：周一找 5 个对象 → 周二准备针对性案例 → 周三发送 → 一周后最多跟进一次 → 核对链接和引荐转化。
锚文本自然，商业合作标 `sponsored` / `nofollow`。**不买**高 DR 套餐、无关页插链、站群、论坛签名、新闻稿铺网、保证排名服务。

## 7. 广告

**买量**：前 30 天不投。启动条件——支付 / 取消 / 退款 / 归因跑通，有效处理成功率约 90%，
约 10 位真实付费者，明确词与功能页的对应。首轮 800–1,500 元、7–14 天、只测美国桌面。
分「主转换词 → 首页」和「工作流词 → 功能页」两组，只用精确 / 词组匹配，不投竞品品牌词。

**算账**：CAC = 广告花费 ÷ 新增付费客户（按退款后）。Pro $12 × 假设 80% 贡献率 = $9.60/月，
没有续费证据时 CAC 控制在约 $8–10。点击到付费 1% 时，可承受 CPC 只有约 $0.08–0.10。
分组花到目标 CAC 的约 3 倍仍无付费就暂停检查；首轮用完仍不合理，不加预算。

**站内展示广告**：前 90 天不挂。免费页月浏览达到约 3–5 万后，才在教程区小规模试；付费用户不显示广告。

## 9. 收入情景（算例，不是预测）

漏斗假设：合格访问 × 40% 开始转换 × 80% 成功导出 × 1% 首次付费；付费者 60% 买 Pass、40% 买 Pro。

| 月合格访问 | 新增付费（期望） | 新增首笔收入 | 新增 Pro MRR |
|-|-|-|-|
| 2,000 | 6.4 | $57.60 | $30.72 |
| 5,000 | 16 | $144 | $76.80 |
| 15,000 | 48 | $432 | $230.40 |

$1,000 MRR 约需 84 名 $12 订阅者；按假设 10% 月流失，每月要新增 8–9 人维持。
前三个月的合理目标是拿到**有人用、有人付费、有人再付费或续订**的证据，而不是承诺 $1,000 MRR。
同时记录支持时长：每位订阅者都要人工修音符的话，产品会变成低价服务。

## 10. 90 天执行表

| 时间 | 交付 | 判断 |
|-|-|-|
| 第 1 周 | 明确样本、本地转录原型、与免费方案比较、核定域名 | 清晰样本能否可靠出可用草稿 |
| 第 2–3 周 | 免费转换器、试听、参数、导出、3 个示例、错误处理；上线核心页与政策页 | 首个完整任务能否顺利做完；记录来源与完成事件 |
| 第 4 周 | 扩充质量测试；5 位目标用户试用；首批 2 篇教程 | 他们在哪一步返工，批量与清理有无真实价值 |
| 第 5–6 周 | 批量、清理预设、支付与取消；上线 $7 / $12 收费测试 | 是否有人为效率付费 |

| 第 9–10 周 | 按 Search Console 改标题 / 说明 / 内链；修最大失败原因 | 曝光、点击、导出、复用哪一环卡住 |
| 第 11–12 周 | 检查付费者后续使用、Pass 再购、续费；写继续 / 收缩决定 | 留存和单位经济是否支持第二批资金 |

时间分配：早期开发 / 质量 60%、教程与获客 25%、数据与支持 15%；上线后开发降到约 40%。不要连续 90 天只写代码。

## 11. 指标与第 90 天决策

事件链：页面访问 → 加载示例 / 选择文件 → 开始转换 → 转换完成 → A/B 试听 → 免费导出 →
尝试批量 / 清理 → 进入结账 → 付款 → 退款 / 再次使用 / 续费。按来源、落地页、国家、设备分开看；
不记录音频或文件名。（前半段已埋点并在 GA4「MidiDraft 看板」里，见 `docs/analytics.md`；
批量、结账、付款的事件等第 2 阶段再加。）

| 指标 | 初始内部阈值 |
|-|-|
| 有效输入完成率 | 目标 ≥ 90%；低于 80% 先停获客扩张 |
| 7 天再次使用率 | 明显低于 10% 时，调查是否本就是一次性需求（不自动否定 Pass） |
| 成功用户首付率 | 先以 1% 为实验目标 |
| 付费节省时间 | 目标约 30%，达不到就改变收费范围 |
| 退款与支持 | 质量退款重复出现时，先修质量，不加广告 |
| 搜索表现 | 看 4–6 周趋势，不以某天排名定输赢 |

**第 90 天四种决定：**

- **继续投入**：累计约 20 个真实付费客户，其中至少 5 个独立用户再次购买或续费；清晰素材完成率稳定；来源可复现。
- **保留免费站、停止订阅扩张**：观察约 500 位合格成功用户后付费仍极少，且批处理不显著省时。
- **仅延长 SEO 观察**：产品能用、有少量付费，但新域名搜索仍小；曝光持续增长时，不加预算和功能再观察 4–8 周。
- **停止或转向**：清晰单乐器长期达不到质量线；约 10 位真实目标用户都认为结果不值得编辑；或必须靠高额云成本才能达到免费竞品基线。

若用户只买 Pass、不愿订阅：接受低频工具生意，保留一次性套餐，不为展示 MRR 强推订阅。
